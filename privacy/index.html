What this site collects

The Sound Question website currently has no contact forms, user accounts, analytics scripts, ad pixels, or marketing cookies. Visiting it does not require submitting personal information.

Hosting and external services

The site is hosted through Cloudflare Pages. Like other hosting providers, Cloudflare may process technical request information for delivering and securing the website. Following a link to YouTube, Instagram, TikTok, or Threads takes you to those services, which have their own privacy practices.

Changes

If tracking, embedded media, or contact forms are added later, this notice should be updated before those features go live.
